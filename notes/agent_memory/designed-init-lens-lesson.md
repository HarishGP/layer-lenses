Harish's hand-designed init (`src/layer_lenses/designed_init.py`, notebook `notebooks/designed_init_u0.ipynb`): a probe neuron orthogonal to all ODT normals, 32 neurons on signed level-4 normals, four second-layer groups wiring the probe with +-1 to left/right-subtree level-4 neurons, random 0/1 third layer, all-ones output.

Findings: a second-layer unit receiving +ReLU(probe) is on whenever the probe is on, so groups with probe weight +1 are inert and groups with -1 are informative; left-subtree informative groups push the probe toward -u_0, right-subtree toward +u_0, verified in sign for all 16 patterns at t=0. Under full-batch flow any pattern with an inert group stalls at |cos| ~0.45 with 80% level-4 content; patterns with no inert group reach |cos| ~0.9. Shrinking the inert weight below ~0.1 flips the endpoint from stall to u_0 even though the initial u_0 push gets smaller. Label convention: y = +1 iff the on-path level-4 split is positive.

Extended Sep 29: `two_probe_spec` (probe 0 -> +u_0 via C/D-type groups, probe 1 -> -u_0 via A/B-type, all probe weights -1, identity layer 3, output scale 20) sends both probes to |cos| 0.9-0.93 with no cue neuron dragged along. `cue_mode="linear"` (read each level-4 pair as +1/-1, a linear coordinate) gives an 8x stronger first-order push; it mirrors the learned nets, where units reading opposite-pole u_0 neurons give them opposite signs 77% by magnitude at loss 0.3. Learned outgoing weights of u_0 neurons are NOT predominantly negative (46-50%). Identity layer 3 with output 20 equals random 0/1 layer 3 exactly; a balanced-sign output kills the probe (unexplained). Loss never drops below 0.67 in any designed run; the design decides directions only.

Six probes (Sep 29 afternoon): `node_probe_groups` generalizes the pole rule to any internal node (push sign = -s*side; pair left/right children to cancel ancestors). At t=0 the cancellation is exact. Under the flow: relu cues fail for node probes (captured by u_0); linear cues put every probe on its target; with cues frozen the design is clean but stalls at cosine ~0.52 (node) / 0.65 (root); with cues free the root reaches 0.93 but node probes get growing u_0 leakage as cues drift. The stall = constant part of the lens; that is the next thing to attack.

Full hierarchy under SGD (Sep 29, 48 runs, `HierarchyDesignSpec`, widths 80/40/40, layers 2-4 rescaled to O(1) rows, eps 0.01, batch 1000, lr 0.02, mom 0.9, 100k-step cap): with the 32 cue neurons frozen, probes for levels 0, 1, 2 reach their targets in 100%, 100%, 93-96% of cases in both cue modes; level 3 only 30-38%. With cues free, 20-24 of 32 cues rotate to coarse nodes and node probes mostly fail. No run reached loss 0.3 (0.40-0.43 at the cap). Under SGD the relu/linear distinction stops mattering when cues are frozen.

Follow-ups (Sep 29 evening): releasing the frozen cues at 10k steps keeps levels 0-2 on target in all 12 seeds, recovers the free-condition loss (0.40) and raises level-3 capture to 0.61 (linear). Width 120 in layer 2 does not lower the loss. The ~0.4 loss floor was a scale effect: at Kaiming row norms (1.41) the same wiring reaches loss 0.3 in 34-46k steps like random inits; at the default row norm (0.577) it captures all four levels by 10k but the deep probes drift off later. `standard_scale_spec(scheme)` builds these.

Half-Kaiming (row norm 0.707, 4 seeds, 600k steps, constant lr 0.02): loss plateaus at 0.37-0.38, never 0.3; early capture at 10k is the best seen (1/1/0.88/0.94 free) but deep probes drift off by 100k. Full Kaiming (1.41, logit RMS 2.4) is the only designed scale that reaches 0.3 quickly. None of the designed inits reached 0.1 on a constant LR; the random baseline used cosine annealing.

Cosine annealing (Sep 30, full Kaiming, seed 0, 1M steps, lr 0.02 -> 0.001): the loss floor was the constant LR. Free cues reach loss 0.008 / test error 0.6%, frozen cues 0.010 / 0.7%, both below the random-init cosine baseline (0.047). At the end all 31 tree nodes are covered by first-layer neurons with |cos| > 0.95 (free 60/80 neurons aligned, frozen 76/80). Only about half the probes keep their designed node; the rest and the random neurons are reassigned to cover the remaining nodes. Per-probe "on-target" undercounts what is learned; use node coverage as the metric.

10M points / batch 10k with no random rows, one unit per probe, exact-half layer 3 (Sep 30, cues frozen): probe deviation is NOT a finite-sample effect (17/30 on target; which root probe wins its pole changed between runs, but no probe ever reached the opposite pole of its node) and the 62-30-40 net stalls at loss 0.117 / test error 4.4% because level-3 nodes 8 and 9 are never covered while coarse nodes get 2-3 neurons each. Spare random neurons are what let the 80-40-40 net reach 0.01. `build_data_chunked` (float32, chunked) is needed for 10M points on this machine; a batch-10k step costs the same as batch-1k.

Isolation runs (Sep 30): 62-30-40 at 1M/1k and 80-30-40 at 10M/10k both fell into a dead-second-layer solution: all-ones output + nonnegative layer 3 means logits start positive, and when no output weight turns negative the net fits y=-1 by switching every unit off (logit exactly 0, loss floor ~0.4, `zero_one_loss` reads 50% because a zero logit scores as +1; strict rule gives 8.9% / 2.1%). Which branch a run takes is decided by epoch ~30 and is noise-sensitive (same init went both ways). First-layer capture is unaffected: all-cues designs give 0 opposite-pole captures vs 7 with random cue subsets; 80 rows restore 31/31 coverage. Next: balanced-sign output layer at Kaiming scale.

**Why:** This is the cleanest evidence so far for the lens mechanism: a constant lens component pulls a neuron toward E[y x] (level 4), and only lens modulation by other features can pull toward a coarse direction.
